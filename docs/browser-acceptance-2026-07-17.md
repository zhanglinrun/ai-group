## 发现与处理

首次直接访问旧的 Vite 开发进程时，页面 HTML 可返回但 React 根节点为空，表现为白屏；生产 preview 正常。重启 Vite 开发进程后开发页恢复，判断为旧进程的依赖优化/热更新缓存状态，而非业务代码渲染错误。

遇到相同现象时执行：

```powershell
$ErrorActionPreference = 'Stop'
Set-Location '.\\web'
pnpm dev --host 127.0.0.1 --port 5173
```

如仍白屏，先执行 `pnpm build`，再用 `pnpm preview --host 127.0.0.1 --port 4173` 区分开发服务器缓存问题和生产包问题。
